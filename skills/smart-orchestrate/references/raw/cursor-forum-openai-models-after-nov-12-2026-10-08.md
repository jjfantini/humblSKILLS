OpenAI has announced plans to end its agreement with Cursor following the SpaceX acquisition. The proposed cutoff date is **November 12, 2026**, although it is not yet final.

**Possible impact:**

* OpenAI models provided directly through Cursor may no longer be available.

* Users can still use other models such as Grok, Claude, Gemini, and Composer.

* OpenAI models may remain available in local Chat and Agent using your own API key, with separate API costs.

* Your API key will not cover features such as Tab, Auto, Cloud Agents, Automations, or Cursor CLI.

Cursor CEO Michael Truell said OpenAI models represent only around **5% of Cursor’s traffic** and that discussions with OpenAI are continuing.

Cursor has not yet announced a detailed transition plan. However, its broader strategy appears to focus on developing its own Grok and Composer models using SpaceX’s computing infrastructure while continuing as a multi-model platform.
