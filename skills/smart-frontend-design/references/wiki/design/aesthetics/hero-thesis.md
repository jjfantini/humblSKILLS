## The Hero Is A Thesis

For web designs, the hero states the argument. Open with the **most
characteristic thing in the subject's world**, in whatever form that subject
calls for: a headline, an image, an animation, a live demo, an interactive
moment.

The template answer is a big number with a small label, supporting stats, and a
gradient accent. It is not banned — it is simply the answer that arrives without
being chosen. Use it only when it is genuinely the best option for this subject.

**Incorrect (the default hero, applied to a subject it says nothing about):**

```markdown
Subject: a marketplace for salvaged architectural fixtures.
Hero: "12,000+ items" in 96px, three supporting stats, gradient accent.
```

The number is true and tells the visitor nothing about what makes this place
what it is.

**Correct (the subject's most characteristic artifact, made the hero):**

```markdown
Subject: a marketplace for salvaged architectural fixtures.
Hero: one full-bleed photograph of a single reclaimed brass door handle, shot
like a museum object, with its provenance line set in the same catalogue type
the listings use.
```

Be deliberate about the *form*, not just the content. If the subject is a
developer tool, the characteristic thing may be a live demo rather than any
image. If it is a research group, it may be a single sentence set at size. Ask
what artifact the subject's own world would put in the window.
