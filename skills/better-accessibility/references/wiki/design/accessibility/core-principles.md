## Better Accessibility Core Principles

Review product interfaces for keyboard, semantic, form, screen-reader, target-size, motion, and zoom accessibility.

### Review lens

- Inspect the current interface, runtime state, and project conventions before reaching a judgment.
- Report only confirmed domain findings with exact evidence, an actionable change, and relevant verification.
- Stay read-only for review requests; implement only when the user explicitly expands the scope.
